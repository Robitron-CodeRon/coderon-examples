# Örnek dizinleri
Her gerçek örneği `examples/<kalıcı-kimlik>/` altında tutun. Alt dizinler: `README.md`, `src/`, isteğe bağlı `assets/` ve gerçek paket için `dist/`. Konu ve kart sınıflandırması katalog üzerinden yapılır; kart başına sabit klasör zorunluluğu yoktur.

Henüz gerçek örnek veya `.ron` paketi yoktur. `templates/` katalogda listelenmez.
